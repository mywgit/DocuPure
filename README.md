## 🌟 Key Features

- **🔒 100% Client-Side Privacy**: Built with WebAssembly and `pdf-lib`. Your documents never leave your local machine sandbox.
- **⚡ Unlimited & Free**: No daily limits, no subscription paywalls, no artificial file waiting queues.
- **📑 Core High-Volume Tools**:
  - **[Merge PDF](https://pdf.puretoolhub.com/merge-pdf)**: Combine multiple PDF files into one with intuitive drag-and-drop ordering.
  - **[Split & Extract PDF](https://pdf.puretoolhub.com/split-pdf)**: Extract specific page ranges or download every page as a clean ZIP archive.
  - **[Images to PDF](https://pdf.puretoolhub.com/jpg-to-pdf)**: Convert JPG, PNG, and WebP images into standard A4 documents.
  - **[Compress PDF](https://pdf.puretoolhub.com/compress-pdf)**: In-browser byte stream optimization and image downsampling.
  - **[Protect & Watermark PDF](https://pdf.puretoolhub.com/protect-pdf)**: Stamp diagonal text watermarks and copyright notices.
- **🌐 7 Native Languages**: English, Spanish, Portuguese, German, French, Japanese, and Simplified Chinese.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide React
- **PDF Engine**: `pdf-lib`, `jszip`
- **Analytics**: Google Analytics 4 + Microsoft Clarity
- **Deployment**: [Vercel Global Edge Network](https://vercel.com/)

## 💻 Local Development

```bash
git clone https://github.com/mywgit/DocuPure.git
cd DocuPure
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
