# 📄 DocuPure - 100% In-Browser Privacy-First PDF Studio

> **Fast, Unlimited & 100% Private PDF Web Utilities.**  
> Merge, split, compress, convert images, and protect PDF files directly in your browser memory.  
> Zero server uploads, zero file tracking, and 100% free forever.

---

## 🚀 Key Features

- **🔒 100% Client-Side Privacy**: Built with `pdf-lib` and WebAssembly. Files never leave the browser sandbox.
- **⚡ Unlimited & Free**: No daily limits, no artificial quotas, no countdown timers.
- **📑 6 Core High-Volume Tools**:
  - `Merge PDF` (`/merge-pdf`): Merge multiple PDFs with drag-and-drop ordering.
  - `Split & Extract PDF` (`/split-pdf`): Extract page ranges or split every page into a ZIP.
  - `Images to PDF` (`/jpg-to-pdf`): Convert JPG, PNG, and WebP images to standard A4/Fit PDFs.
  - `Compress PDF` (`/compress-pdf`): In-browser stream optimization and size reduction.
  - `Protect & Watermark PDF` (`/protect-pdf`): Add diagonal text copyright watermarks.
- **🌐 7 Languages i18n**: English, Spanish, Portuguese, German, French, Japanese, Simplified Chinese.
- **⚔️ Competitor Intercept Pages**: `/ilovepdf-alternative`, `/smallpdf-alternative`, `/adobe-acrobat-alternative`.
- **🔗 PureToolHub Matrix Ecosystem**: Triangular internal links connecting ToolHub, CalcHub, and SnapBio.
